# Лабораторні роботи з Linux Кулєшов Максим ІО-52

[![Language - Bash](https://img.shields.io/badge/Language-Bash-4EAA25?logo=gnu-bash&logoColor=white)](https://www.gnu.org/software/bash/)

Цей репозиторій містить набір Bash-скриптів, розроблених у рамках виконання лабораторних робіт з вивчення операційних систем (Варіант 8). Скрипти автоматизують роботу з текстом, файловою системою, процесами та потоками вводу/виводу.

## (Варіант 8)

*   **Лабораторна робота №2: Обробка тексту та регулярні вирази**
    *   Підрахунок кількості слів у файлах (`wc`).
    *   Парсинг `/etc/passwd` (виведення 1 та 6 полів через `cut`).
    *   Зворотне сортування тексту та заміна символів за допомогою `sed`.
    *   Фільтрація рядків за кількома умовами та розділення файлів на частини.
*   **Лабораторна робота №3: Потоки та конвейєри**
    *   Перенаправлення стандартних потоків (`stdin`, `stdout`, `stderr`).
    *   Фільтрація слів визначеної довжини за допомогою регулярних виразів.
    *   Пошук користувачів у системі на основі доступних оболонок з `/etc/shells`.
*   **Лабораторна робота №4: Файлова система та пошук**
    *   Автоматизоване створення каталогів (наприклад, `ggg`) та файлів.
    *   Пошук файлів без пропусків у назві та виведення їх вмісту.
    *   Глобальний пошук файлів за часом модифікації (від 3 до 5 днів тому) через `find`.
*   **Лабораторна робота №5: Управління процесами**
    *   Запуск та переведення процесів у фоновий режим (`sleep 1000 &`).
    *   Моніторинг процесів: виведення PID, імені користувача, команди та часу запуску через `ps`.
    *   Побудова дерева процесів (`pstree`) та безпечне завершення фонових задач (`kill`).
